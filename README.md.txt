# Healthcare Risk Data Analysis

## Project Overview
This project analyzes health-related data to explore factors associated with diabetes and build machine learning models to predict diabetes status.

## Dataset
The dataset contains 100,000 records and nine columns, including:
- Gender
- Age
- Hypertension
- Heart disease
- Smoking history
- Body Mass Index (BMI)
- HbA1c level
- Blood glucose level
- Diabetes status

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Load and explore the dataset.
2. Check for missing values and remove duplicate records.
3. Perform exploratory data analysis and visualization.
4. Encode categorical variables.
5. Split the data into training and testing sets.
6. Train Logistic Regression and Balanced Logistic Regression models.
7. Compare model performance using accuracy, precision, recall, and F1-score.

## Key Findings
- The original dataset contained 100,000 records.
- After removing duplicate rows, 96,146 records remained.
- Standard Logistic Regression achieved approximately 96.0% accuracy.
- Balanced Logistic Regression achieved approximately 88.0% recall, helping it identify more actual positive cases.

## Disclaimer
This is an educational data analysis and machine learning project. Its predictions are not intended for medical diagnosis.
